# Helix at ASHG 2026 — booth showcase

A silent, automatically looping 16:9 showcase for the Helix booth monitor.

## Playback

Open the GitHub Pages site in Chrome or Edge. It begins automatically and repeats every 2 minutes 36 seconds. Double-click the presentation or press **F** for full screen. Press **Space** to pause or resume, or use the arrow keys to move between scenes. The navigation dots select a scene. Controls hide after a few seconds.

The page includes its fonts, artwork, QR codes, and Explorer demo, with no external dependencies. Download `index.html` to use it offline.

## Sequence

1. Featured plenary
2. Platform talks
3. Thursday posters
4. Friday proteomics posters
5. Friday pharmacogenomics posters
6. GenoSphere data
7. Helix Explorer platform and demo
8. Research Access Program
9. HelixReplicates
10. Closing
