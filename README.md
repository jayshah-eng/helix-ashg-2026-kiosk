# Helix at ASHG 2026 — booth showcase

A silent, automatically looping 16:9 showcase for the Helix booth monitor.

## Playback

Open the GitHub Pages site in Chrome or Edge. It begins automatically and repeats every 2 minutes 44 seconds. Double-click the presentation or press **F** for full screen. Press **Space** to pause or resume, or use the arrow keys to move between scenes. The navigation dots select a scene. Controls hide after a few seconds.

The page includes its fonts, artwork, QR codes, and Explorer demo, with no external dependencies. Download `index.html` to use it offline.

## Sequence

1. Welcome: Research. Data. Platform.
2. Featured plenary
3. Platform talks
4. Thursday posters
5. Friday proteomics posters
6. Friday pharmacogenomics posters
7. GenoSphere data (600K+ individuals)
8. Helix Explorer platform and demo
9. Research Access Program
10. HelixReplicates
11. Closing

The full kidney-function and GLP-1 talk titles are shown; the collider-bias title retains its concise wording.
